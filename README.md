# Food Delivery Data Analysis

## Project Overview
This project focuses on analyzing food delivery order data using Python. The goal is to clean the dataset, explore order patterns, understand delivery performance, and calculate platform revenue.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset contains food delivery order information, including:
- Order and customer details
- Restaurant information
- Order and delivery timestamps
- Order value and delivery fees
- Payment methods
- Discounts and offers
- Weather conditions
- Order channels

## Project Tasks
1. Load and understand the dataset.
2. Clean missing values and duplicate records.
3. Perform data preprocessing.
4. Create new columns for delivery time and revenue analysis.
5. Perform exploratory data analysis (EDA).
6. Analyze order trends and delivery performance.
7. Create visualizations.
8. Validate the cleaned dataset and results.

## Key Findings
- Original dataset contained 1,010 rows.
- Removed 10 duplicate records.
- Final cleaned dataset contains 1,000 rows.
- Average delivery time was approximately 73.58 minutes.
- Mobile App was the most frequently used order channel.
- COD was the most frequently used payment method.

## How to Run
1. Download or clone this repository.
2. Open `food analysis.ipynb` in Jupyter Notebook.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells in order.
